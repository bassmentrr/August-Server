# August Server

August Server is a server implementation primarily tested against an **August 17th, 2016 build of Rec Room**.

It will probably work with all versions **older than August 17th, 2016** as well, although compatibility with those versions has not been tested because I am a lazy bum.

## Building

Make sure you have **.NET 9.0** installed.

### 1. Clone the repository

```bash
git clone https://github.com/bassmentrr/August-Server.git
cd August-Server
```
or if your lazy, just download the zip from github!

### 2. Build the server

```bash
dotnet build
```

### 3. Run the server

```bash
dotnet run
```

The server should run on port 6000!

I don't recall why I chose port 6000 but oh well, it's easy to change.
